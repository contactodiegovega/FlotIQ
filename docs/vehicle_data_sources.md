# FlotIQ — Fuentes de vehículos eléctricos

## Objetivo

Recopilar especificaciones técnicas verificables de vehículos eléctricos adecuados para una flota profesional de 50 VTC en Madrid.

## Variables necesarias

- Fabricante
- Modelo
- Versión y año
- Capacidad útil de batería (kWh)
- Consumo energético (kWh/100 km)
- Autonomía homologada WLTP (km)
- Potencia máxima de carga AC (kW)
- Fuente y fecha de consulta

## Criterios de selección

1. Vehículos eléctricos puros (BEV).
2. Modelos comercializados en España.
3. Adecuados para servicios profesionales de transporte.
4. Especificaciones técnicas documentadas.
5. Compatibilidad con carga AC de hasta 11 kW, o consideración explícita de un límite inferior.

## Política de datos

Las especificaciones técnicas se obtendrán de fuentes verificables. La composición final de la flota será un escenario simulado, no un inventario real de una empresa existente.

No se utilizarán matrículas ni identificadores personales reales.
